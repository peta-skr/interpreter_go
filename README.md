# interpreter_go

『Go言語でつくるインタプリタ』（Thorsten Ball）に沿って、Monkey言語のインタプリタをGoで書き始めたもの。第1章の字句解析と、第2章の構文解析の途中（`let` 文・`return` 文と、識別子・整数・前置演算子・中置演算子の式）まで進めたところで止まっている。

`let` 文と `return` 文の右辺はまだ読み飛ばしていて、評価器は無い。同じ本はこの後、JavaScriptで書き直した [monkey_js](https://github.com/peta-skr/monkey_js) で第3章の途中まで進めている。

## 動かし方

```sh
go run .        # REPLを起動。入力した行をトークンの列にして表示する
go test ./...   # 字句解析・構文解析・ASTのテスト
```

`go.mod` の指定は `go 1.21.5`。外部パッケージは使っていない。

## 使った技術

- Go
- Prattパーサ（トークンの種類ごとに前置・中置の解析関数を登録し、優先順位の表で結合を決める方式）

## 学んだこと

- ソースコードを1文字ずつ読んでトークンに分ける字句解析の手順
- Prattパーサで演算子の優先順位を扱う方法と、入力と期待値を表に並べるテストの書き方
